#Code with Mosh Clone

A modern, responsive educational website clone built with HTML, CSS, and Bootstrap, focused on clean layouts, responsive design, interactive navigation, animations, and an engaging learning-platform interface.

## 🚀 Live Demo

[View Live Website](https://code-with-mosh-clone.vercel.app/)

## 📌 About the Project

This project is a front-end clone inspired by the Code with Mosh website.

The website was built to practice responsive web design, Bootstrap components, typography, layouts, navigation, animations, and working with external media resources.

The project was developed with a tutorial/reference as part of my learning process, with a focus on understanding and implementing the frontend concepts used throughout the website.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Bootstrap 5 responsive layout
- Responsive navigation with mobile offcanvas menu
- Hero section with call-to-action
- Embedded promotional video
- Statistics section
- Feature sections with responsive layouts
- SVG icons
- Animated hero content
- Responsive footer
- Social media icons
- Modern dark-themed UI
- Mobile-friendly design

## 🛠️ Tech Stack

## 🎨 UI & Interaction

The project focuses on creating a polished educational-platform interface through:

- Responsive Bootstrap grid system
- Offcanvas mobile navigation
- Hover and button interactions
- CSS-based styling and layouts
- Animated hero content
- Responsive media sections
- Embedded external video
- Custom typography

## 📱 Responsive Design

The website is designed to adapt to different screen sizes using Bootstrap's responsive grid system and custom CSS media queries.

Desktop, tablet, and mobile layouts are adjusted to provide a consistent and usable experience across different devices.

## 🎬 Media

The promotional video is loaded using an external CDN URL rather than being stored directly in the repository.
